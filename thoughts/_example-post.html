TL;DR

Every post is one HTML file in thoughts/. This page shows each building block, and the source has a comment above each one.

This is the opening paragraph. The lead class makes it a little larger, and drop-cap adds the big serif first letter. Use them on the first paragraph only, or leave them off for a plainer look.

Regular paragraphs look like this. Keep them short: three or four sentences reads well on a phone.

Text and formatting

You can write bold, italic, and links. Use inline code for function names like get_user(), highlight a key phrase, or strike out a correction. Keyboard shortcuts look like ⌘ + K. Hover over RAG to see an abbreviation. Small text like H2O and x2 works too.

A subsection

Add class="serif" to any paragraph to set it in the serif font, which is the same one the titles use.

Code

Code blocks scroll sideways if a line is long. Set data-file to show a filename bar, or leave it out.

def prefetch(doc_id, depth=2):
    # Warm the cache with documents the user is likely to open next
    for nxt in predict_next(doc_id, depth):
        redis.set(f"doc:{nxt}", load(nxt), ex=300)
